# ADR-0003: LLM-классификация вместо rules.yml

- **Дата:** 2026-08-24
- **Статус:** accepted

## Context

Rules-based классификация (`configs/rules.yml`) имеет точность ~60%. Частые ошибки определения проекта и типа задачи.

## Decision

Использовать локальную LLM (Ollama, модель `email-assistant-v2`) для анализа писем. Rules оставить как fallback при недоступности AI.

## Consequences

- Точность >85%
- Понимание контекста цепочки
- Требуется GPU для Ollama
- Асинхронная обработка через очередь
