# ADR-0001: Замена Plane на собственный helpdesk

- **Дата:** 2026-08-24
- **Статус:** accepted

## Context

Plane использовался как база задач, но:
- Нельзя сменить проект задачи — ошибка классификации фатальна
- Нет единого потока для руководителя
- Нет интеграции с GitHub в бесплатной версии
- Plane ограничивает, а не помогает

## Decision

Отказаться от Plane. Создать собственный helpdesk:
- Лента входящих (`inbox_items`)
- Задачи (`tasks`) с доменными статусами
- Vue 3 фронтенд с дашбордом
- SQLite как хранилище

## Consequences

- Полный контроль над функционалом
- Отсутствие ограничений стороннего сервиса
- Больше кода для поддержки
- Возможность расширения на другие источники (Telegram, веб-формы)
