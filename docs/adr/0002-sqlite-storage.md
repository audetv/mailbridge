# ADR-0002: SQLite как хранилище

- **Дата:** 2026-08-24
- **Статус:** accepted

## Context

Нужна база данных для одного пользователя/маленькой команды. Требования:
- Простота развёртывания
- Нет отдельного сервера БД
- Достаточно надёжности

## Decision

Использовать SQLite с WAL-режимом.

## Consequences

- Один файл — просто бэкапить
- Нет сетевых задержек
- Ограничение на конкурентную запись (но для масштаба ок)
- Миграции через `internal/store/sqlite/sqlite.go`
