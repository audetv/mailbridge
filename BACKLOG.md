# BACKLOG — Mailbridge (захват идей и болей)

> **Правило захвата (2026-09-17; правила-апд 2026-09-20, режим B «практики файла захвата»).**
> Одна строка = одна идея: `дата — суть (— откуда/повод, опционально)`.
> Без деталей, без сроков, без оценок — **обсуждаем потом**. Сюда входит то, что «в процессе пользования, хорошо бы так-то»;
> концепционные/философские мысли (онтология, «почему») — НЕ сюда, а в `docs/` контейнера (ADR-0004, не в репо).
>
> **Команда (режим-правило):** владелец в любой момент может сказать **«добавь в бэклог: …»** —
> агент добавляет строку сюда (формат выше) и ничего больше не решает.
>
> **Закрытые (2026-09-20):** раздел `## Закрыто` — 1 строка + указатель, куда идея ушла (`v0.Х`/`archive/PLAN.vХ.Y.md`/issue/«отложено: решение»).
> Реализованное НЕ живёт в «Идеи» — история уже есть в CHANGELOG/архиве/issue; purge — на closeout релиза или в режиме B (агент сам предлагает перенос).
> Идея, ставшая issue, — обязательная ссылка на issue в строке (issue = живой контекст, PR #82): бэклог не расползается в параллельный трекетер.
> Старение: идея без движения >2 мес — при ближайшем purging вопрос «всё ещё?».
> Не registry: статусы «в работе/blocked» — это ROADMAP/PLAN/issue; строка, требующая статуса, — уже не захват.

## Поток

```
BACKLOG.md (идея, захват)

```
