# Mailbridge

Интерактивный почтовый шлюз между email и [Plane](https://plane.so).

## Возможности

- Приём задач через email → создание в Plane
- Двухсторонняя синхронизация комментариев
- NLP-классификация (определение проекта, типа, приоритета)
- Обработка вложений (скриншоты, документы)
- Urgency Booster (автоповышение приоритета по срочным словам)
- Гарантированная доставка ответов через outbox
- Graceful shutdown, health checks, метрики

## Стек

- Go 1.26+
- SQLite (с возможностью перехода на PostgreSQL)
- IMAP/SMTP
