# План: Реархитектура хранения — лента, цепочки, задачи

## Концепция

- **Лента (inbox_items)** — универсальный поток входящих данных (email, telegram, формы, webhook)
- **Цепочки (threads)** — группировка элементов ленты
- **Задачи (tasks)** — выбранные из ленты элементы, требующие действия
- **AI-очередь** — асинхронная обработка входящих через LLM с retry

## Статусы задач

| Статус | Значение |
|--------|----------|
| `new` | Новая, не отсмотрена |
| `backlog` | Отсмотрена, отложена |
| `in_progress` | В работе |
| `completed` | Выполнена |
| `closed` | Закрыта/архивирована |

## Статусы элементов ленты

| Статус | Значение |
|--------|----------|
| `unread` | Не прочитан |
| `read` | Прочитан |
| `archived` | В архиве |

## AI-обработка

| Поле | Значение |
|------|----------|
| `ai_processed = 0` | Ожидает обработки |
| `ai_processed = 1` | Обработано успешно |
| `ai_processed = -1` | Ошибка после N попыток |
| `ai_attempts` | Количество попыток |
