**Статус:** CLOSED → RELEASED → DEPLOYED. PR #70 (quote, squash `8e6f493`) + PR #71 (тест-флейк TaskTableDue) → `main` `218d6e9`, CI pass, 153/153; тег `v0.27.3` → `218d6e9` (Release + бинарник `0.27.3 (commit: 218d6e9, built: 2026-09-18_23:05:59)` проверен из Release-артефакта); тройка пройдена: визуал владельца 2026-09-19 «визуал, ок» (задача 416) + «выпускай тег». **Прод :8080 — задеплоен 2026-09-19 02:09 МСК** через `deploy-released.sh v0.27.3` (`0.27.2 (51a8273)` → `0.27.3 (218d6e9)`, health 200, `/api/version` = `0.27.3 (218d6e9)`, «Затронуто в письме» в прод-чанке `assets/TaskDetailView-B_uVE943.js`; журнал `~/apps/mailbridge/deploy.log`).

**Контекст (из записей, верифицировано):**
- Спроектировано в `archive/PLAN.v0.23.md:161`: «`quote` — дословные 1–2 строки из письма-ответа… рендерится blockquote **над саммари** (подпись «Затронуто в письме»). `body` остаётся чистым саммари → копирование MD/TXT не ломается».
- Финальное решение 15.09 (CHANGELOG [0.23.0]) убрало quote только из `ai_verdict`. Промпт-контракт quote сохранён (`internal/ai/orchestrator.go`: «дословные 1–3 строки из ТЕКУЩЕГО письма… Если фрагмент выделить нельзя — quote = `""`») → модель кладёт quote в `verdict_json` и саммари-комментария.
- Реальные записи (задача 416): `task_comments.id 226/230` — `kind='user_comment'`, `verdict_json={"quote":"…"}`; дубли — `ai_verdict` 227/231 с тем же quote.
- UI (`CommentList.vue`): quote раньше нигде не читался (только CSS markdown-blockquote).

**Иерархия (по решению владельца 2026-09-18):** саммари (своими словами, сразу на виду) → **цитата дословно, подкреплает саммари** → «Оригинал письма» — под спойлером, когда нужен полный контекст.

**Решение (вариант 1, согласован; только фронтенд):**
- В комментарии-саммари (предикат `isAIUserSummary()`), **между бейджем «AI-саммари» и body** — блок: подпись `Затронуто в письме` + quote (левая рамка/italics, как markdown-blockquote).
- **Источник quote (правило дубля, решение владельца):** показываем из **саммари-комментария (`user_comment`)** — его собственный `verdict_json.quote`; если пуст — fallback на `ai_verdict` того же письма (связь `inbox_item_id`) с тем же `quote`; если оба пусты/отсутствуют — **блок не рендерится вообще**.
- Edge-cases: legacy-саммари `author='user'` (до 15.09) → блок отсутствует; `quote: ""` / нет `verdict_json` / malformed JSON → молча пропускаем (try/catch); `ai_verdict`-комментарии — quote НЕ показываем (решение 15.09); `body` и экспорт MD/TXT — не тронуты (quote не дублируется в саммари).
- Бэкенд, API, схема, данные, промпт — **не меняются** (данные уже в `verdict_json`).

Изменены ТОЛЬКО 2 файла фронта: `frontend/src/components/CommentList.vue` (блок quote + `parseQuote`/`summaryQuote` + стили `.comment-quote*`) + `frontend/tests/components/CommentList.spec.js` (8 кейсов, RED→GREEN).
